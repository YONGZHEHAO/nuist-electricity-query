# 隐私说明

本工具面向个人在自己的 Windows 设备上查询已获授权的宿舍电量。公开仓库和发行包不包含可用登录凭据、个人宿舍参数、真实历史记录或原项目的个人路径。

## 在本机保存什么

数据目录为当前 Windows 用户的 `%LOCALAPPDATA%\NuistElectricityQuery\`。

| 数据 | 保存方式 | 注意事项 |
| --- | --- | --- |
| 房间显示名、查询参数 | `config.json` | 不包含明文授权请求头，但房间内部标识仍可能关联到个人。 |
| 敏感授权请求头 | `credentials.dat`，Windows DPAPI 加密 | 绑定当前 Windows 用户；不要分享、提交仓库或随发行包分发。 |
| 查询成功后的电量及观测时间 | 各房间配置独立的 `history.csv` | 能反映一定的在宿舍 / 用电规律，应视为个人数据。 |

房间配置哈希用于隔离历史记录，不是匿名化机制。能读取本机配置或已知房间参数的人，仍可能识别记录所属房间。

DPAPI 降低磁盘文件被直接读取的风险，不能防御当前 Windows 用户权限下的所有恶意软件。查询时程序需要在内存中解密并发送授权信息，授权信息也可能受系统备份、调试器和设备管理策略影响。

## 请求发送给谁

正常查询会向所实现的学校服务发送设置中的查询参数和必要授权请求头。是否允许访问、返回什么数据及授权何时过期，由学校服务决定。

项目不设置维护者的遥测、远程日志上传、个人账号同步或云端历史存储服务。公开版移除了原个人实现中的微信磁盘凭据扫描、支付 / 充值功能、个人宿舍硬编码和桌面伴随应用特例。

`-Demo` 使用完全虚构的演示数据，不读取真实配置凭据或真实历史，也不发起网络查询。它适合截图、录屏和展示界面。

## 分享和贡献前

不要上传或提交：

- `config.json`、`credentials.dat`、真实 `history.csv` 及其备份。
- Cookie、`Authorization`、`synjones-auth`、学号、姓名、可关联个人的房间信息。
- 原始 HAR、完整请求 / 响应、个人日志和未经检查的真实截图。
- 含上述数据的 ZIP、安装包、Git 历史或临时文件。

即使删掉 token 的部分字符，其他字段和请求参数仍可能泄露个人信息。优先使用演示模式复现界面问题，用虚构参数描述流程，不要直接分享整份运行目录。

## 停用与清理

关闭工具后，可以删除 `%LOCALAPPDATA%\NuistElectricityQuery\` 中的个人配置、凭据及历史文件，以清理本工具保存在该位置的数据。清理前如需保留历史，请自行做私密备份；删除历史不可由工具恢复。

删除本机文件不会使已泄露的 token 在服务端失效。如果凭据已经外泄，应立即通过学校支持的方式退出登录、重新登录或联系学校服务方处理，同时删除公开副本。遇到误提交请参阅 [安全说明](../SECURITY.md)。
