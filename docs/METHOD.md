# 配置与查询方法

本项目展示一种个人授权后查询宿舍剩余电量的方法。先在学校官方页面完成正常登录，并确认自己有权查询目标房间；工具只重复执行你已经获准执行的查询。不要尝试枚举房间、借用其他人的登录状态或批量访问其他人的数据。

## 先确认官方查询可用

1. 从学校提供的官方入口进入电费查询页面，完成本人登录。
2. 选择自己的校区、楼栋和房间，确认页面能正常显示剩余电量。
3. 如果官方页面本身报错、登录过期或没有权限，请先解决该问题。工具无法补充账号权限。

本实现历史上观察到的查询路径为 `https://icard.nuist.edu.cn/charge/feeitem/getThirdData`。这是历史实现线索，不是校方公开 API 承诺，也不表示当前仍然可用。使用前应在自己的官方查询页面验证实际请求。

## 手动查看本人查询请求

如果可以在电脑浏览器中正常打开官方查询页面，可使用该浏览器自带的开发者工具：

1. 打开开发者工具的 Network（网络）面板。
2. 在官方页面执行一次本人房间的电量查询。
3. 找到返回剩余电量的请求，分别查看请求参数和请求头。请求可能由多个步骤组成，应以实际成功的查询请求为准。
4. 只将必要字段填入桌面工具的“设置”，不要导出或上传完整网络记录。

部分入口只能在微信等特定容器内完成登录，电脑浏览器不一定支持相同流程。如果无法查看本人授权后的成功请求，应继续使用官方入口；本项目不提供破解容器、绕过登录或自动扫描其他应用凭据的办法。

## 设置字段

下表描述工具使用的字段；实际值应来自你自己的成功查询请求，不要照抄别人的参数。

| 设置项 | 用途 |
| --- | --- |
| 房间显示名 | 仅用于本地界面展示，可自定义，不决定查询目标。 |
| `feeitemid` | 缴费 / 查询项目标识，以本人页面请求为准。 |
| `type` | 页面查询类型参数，含义及值以当前学校实现为准。 |
| `level` | 页面查询层级参数，含义及值以当前学校实现为准。 |
| `xiaoqu_id` | 校区内部标识，不一定等于页面显示文字。 |
| `loudong_id` | 楼栋内部标识，不一定等于楼栋名称。 |
| `room_id` | 房间内部标识，不一定等于可见房间号。 |
| `Authorization` | 本人成功请求所使用的完整授权请求头值。 |
| `synjones-auth` | 本人成功请求所使用的授权 token / 请求头值。 |

授权信息是敏感凭据。项目没有通用 token、通用密码或内置的有效 `Authorization` 值。请保留实际请求中必要的格式和前缀，在本机设置中填写，不要粘贴到 Issue、聊天记录或公开仓库。

保存后可点击刷新检查结果。如果界面显示授权失效，应重新打开官方页面完成登录，再更新设置中的授权字段。仅修改房间显示名不会改变查询对象。

## 常见问题

**官方页面有电量，工具提示授权失效。** 可能是旧 token 过期、复制不完整、请求头格式不一致，或新页面改变了查询流程。以本人最新的成功请求为准；不要反复尝试不属于自己的账号或房间。

**每分钟查询，曲线却没有每分钟下降。** 查询频率与电表 / 服务端数据更新频率不同；连续相同读数可能是正常现象。请合理使用学校服务，遇到限流应降低查询频率或暂停。

**换了房间后原记录不在当前图表。** 工具按房间查询配置分别保存历史。修改内部标识后会进入不同记录分组，原记录仍保留在本机数据目录；不要把不同房间的数据手动拼接成一条曲线。

**想在工具里充值。** 公开版仅交流查询方法，没有支付或充值功能。请使用学校官方缴费入口，并在官方界面确认金额与收款信息。

**想测试但没有授权信息。** 使用 `-Demo`，它只展示虚构数据，不访问学校服务，也不读取你的真实历史记录。
